### SQL Files

- **[Correlated Sub query.sql](Correlated%20Sub%20query.sql)** - Demonstrates the use of correlated subqueries in SQL for advanced data filtering and comparison operations.

- **[Lead and Lag in SQL.sql](Lead%20and%20Lag%20in%20SQL.sql)** - Explores SQL window functions LEAD() and LAG() for accessing data from previous or subsequent rows in a result set.

- **[Month wise cumulative sales.sql](Month%20wise%20cumulative%20sales.sql)** - Calculates cumulative sales figures on a month-by-month basis using SQL aggregation and window functions.

- **[No of business days between two dates.sql](No%20of%20business%20days%20between%20two%20dates.sql)** - Computes the number of business days (excluding weekends) between two given dates in SQL.

- **[Practice Pivot in SQL server.sql](Practice%20Pivot%20in%20SQL%20server.sql)** - Demonstrates the PIVOT operator in SQL Server for converting rows into columns in result sets.

- **[Top 3 and Bottom 3.sql](Top%203%20and%20Bottom%203.sql)** - Query examples showing how to retrieve the top 3 and bottom 3 records from a dataset using SQL ranking functions.

- **[Transform Table.sql](Transform%20Table.sql)** - Contains SQL scripts for transforming table structures and data formats for better analysis.

- **[Unpivot in SQL.sql](Unpivot%20in%20SQL.sql)** - Demonstrates the UNPIVOT operator in SQL Server for converting columns into rows.

### Jupyter Notebooks

- **[Language_Translation_Model.ipynb](Language_Translation_Model.ipynb)** - A Jupyter notebook implementing machine learning models for language translation tasks.

- **[Prompt_Generation_System.ipynb](Prompt_Generation_System.ipynb)** - Explores prompt generation techniques and systems for natural language processing applications.

- **[Tableau_MetaData_Extraction.ipynb](Tableau_MetaData_Extraction.ipynb)** - Demonstrates how to extract and analyze metadata from Tableau workbooks programmatically.

### Tableau & Power BI Files

- **[Combining two datasources to backfill missing data.twbx](Combining%20two%20datasources%20to%20backfill%20missing%20data.twbx)** - A Tableau workbook showing techniques for combining multiple data sources and backfilling missing values.

- **[Regional Sales Dashboard.pbix](Regional%20Sales%20Dashboard.pbix)** - A Power BI dashboard providing comprehensive regional sales analytics and visualizations.
